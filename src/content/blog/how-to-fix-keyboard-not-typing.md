**Start by finding out whether the keyboard fails everywhere or only on one page.** Click a text field, then try typing in a plain text editor. If the editor works, focus on the browser or app. If it does not, check the connection, input settings and keyboard itself.

Work through the checks below in order. Save open work before restarting or changing system settings.

## Is the keyboard not typing only in NinjaType?

Click the [typing area](/) so it has focus. A selected button, address bar or settings field can receive your keys instead of the practice passage.

Check the session state too. A completed practice attempt needs a new session. A multiplayer race waits for players and its countdown before typing begins; after the race ends, the results replace the keyboard section.

If the text area is stuck loading, that can be a page or dictionary request problem rather than a broken keyboard. Reload the page and check whether the passage appears. Then try another browser or a private window. A working private window can help isolate an extension or stored site-data issue, although it does not identify the exact cause.

If clearing site data becomes necessary, remember that NinjaType stores practice history and settings in your browser. Clearing that data can remove them.

## Check the keyboard connection

For an external USB keyboard, reconnect the cable and try another available port. If you use a hub, test a direct connection when possible.

For a wireless keyboard, check its power switch, charge or batteries, and the Bluetooth or receiver connection. Verify that it is connected to the device you are actually using; some keyboards can switch between several devices.

Testing another keyboard on the same computer, or the affected keyboard on another compatible computer, can help separate a keyboard fault from a computer setting. Do not dismantle the keyboard as a first troubleshooting step.

## Check Windows input and accessibility settings

Use the mouse to review the selected keyboard language and layout. A wrong layout often produces unexpected characters rather than no input at all.

In **Settings → Accessibility → Keyboard** on Windows 11, review Filter Keys if short presses appear ignored or delayed. Change it only if it is enabled unexpectedly; accessibility features may be important to the person using the device. Windows versions can use different menu names.

The on-screen keyboard can provide temporary input while you investigate. If the physical keyboard still fails across apps, save your work, restart, and follow the computer or keyboard manufacturer's support guidance.

## Check Mac input and accessibility settings

On current macOS versions, review **System Settings → Accessibility → Keyboard** for Slow Keys, and **Accessibility → Pointer Control** for Mouse Keys. Also check the selected input source.

[Apple’s guide for a Mac that does not respond to key presses](https://support.apple.com/en-us/guide/mac-help/mchlp1240/mac) explains these checks. Slow Keys can require a longer press; Mouse Keys can repurpose keys for pointer movement. Preserve accessibility settings you need and adjust only the feature causing unexpected behavior.

Reconnect an external keyboard or check its wireless connection. If the issue persists in several apps, use Apple or your keyboard manufacturer's troubleshooting steps for your model.

## What if only some keys stop working?

Check whether those keys fail in a text editor too. If they produce different symbols, investigate the input layout first. If a key fails or repeats across applications, inspect for an obstruction and follow the manufacturer's cleaning guidance.

After a spill or visible damage, stop using the affected hardware and seek appropriate service guidance. Repeated typing tests will not repair a physical fault.

## Confirm the fix with a short typing test

Once ordinary text entry works, open [NinjaType practice](/), select a familiar dictionary and complete a short attempt. Check spacing, repeated letters and any keys that failed earlier before trying a speed target.

If the keyboard works but your own key placement feels uncertain, use the [touch typing lessons](/learn/). That is a training problem with a different solution from missing input.
