**10-key typing is numeric data entry using the ten digits on a numeric keypad.** It usually involves the right hand and the keypad on the right side of a full-size keyboard, or a separate external keypad. The name refers to the digits 0 through 9, not to using all ten fingers.

You may encounter it in spreadsheet work, accounting or other tasks that involve entering many numbers. Accuracy matters because a misplaced digit can change the meaning of an entire entry.

## Is 10-key typing the same as touch typing?

No. [Touch typing](/blog/what-is-touch-typing/) is finding keys through learned movements without looking down for each key. It often refers to the main letter keyboard and both hands.

10-key typing focuses on a smaller numeric keypad, usually with one hand. You can use a touch-based technique on that keypad, but an ordinary letter-typing WPM test does not measure the same task.

## Where do your fingers go on a numeric keypad?

On a conventional computer keypad, the middle row is **4, 5, 6**:

| Finger | Common starting position | Digit column |
| --- | --- | --- |
| Index | 4 | 7, 4, 1 |
| Middle | 5 | 8, 5, 2 |
| Ring | 6 | 9, 6, 3 |
| Thumb | Near 0 | 0 |

Many keypads have a raised mark on 5 to help you find the starting position. The little finger may handle Enter, while decimal and operator assignments depend on the keypad and your technique. Follow its actual layout rather than forcing a reach that feels awkward.

Computer keypad layouts commonly put 7, 8, 9 above 4, 5, 6. Phone-style keypads commonly put 1, 2, 3 at the top. Check the device you are practising on.

## What does KPH mean in a 10-key test?

Numeric-entry tests often report **keystrokes per hour (KPH)** with an accuracy measure. Ordinary text tests usually report words per minute using five characters as a standard word unit.

For a test that counts accepted digit presses, the basic calculation is:

**KPH = counted keystrokes ÷ elapsed seconds × 3,600.**

For example, 150 counted keystrokes in sixty seconds gives 9,000 KPH. That illustrates the arithmetic, not a recommended hiring threshold. Providers differ in whether they count Enter, corrections and other keys, and in how they penalize errors. Read the test's rules before comparing results.

## How can you practise 10-key typing?

1. Open a local text editor or spreadsheet and prepare fictional number groups.
2. Find 4, 5, 6 by touch and practise one digit column slowly.
3. Add mixed groups, then zero, decimals and Enter if your task needs them.
4. Compare each entered group with the source before increasing speed.
5. Later, use a dedicated numeric-entry test that states its scoring rules.

Use made-up amounts or identifiers rather than real financial or personal information. Short accurate groups are a useful starting point; there is no need to rush before the layout is familiar.

If the keypad moves a cursor instead of entering digits, check Num Lock where your keyboard provides it. If keys do not respond at all, use the [keyboard troubleshooting guide](/blog/how-to-fix-keyboard-not-typing/).

## Can letter typing practice help?

It can help you build habits such as reading ahead, consistent movement and checking errors, but keypad skill still needs practice on the keypad itself.
