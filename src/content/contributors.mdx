## Your first contribution

1. Read the [README](https://github.com/VivekGupta137/ninjatype#readme) for setup instructions and project conventions.
2. Find an issue you’d like to work on. For larger changes, discuss your approach before starting.
3. Fork the repository and make a focused change on a new branch.
4. Check your change, then open a pull request explaining the problem, the solution, and how you verified it.

Keep contributions focused, respect existing conventions, and be considerate in discussions and reviews.
