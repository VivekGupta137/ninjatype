# NinjaType promotion screenshots

Captured from the live https://www.ninjatype.com site on October 28, 2026.

## Start here

Open `contact-sheet.jpg` to review the gallery. For Product Hunt or app directories, start with these six cards:

1. `gallery/01-practice` — typing practice
2. `gallery/02-touch-typing` — finger lessons
3. `gallery/03-multiplayer` — Quick match and Race with friends
4. `gallery/04-ghost-race` — personal-best shadow challenge
5. `gallery/05-hacker-typer` — simulated terminal
6. `gallery/07-themes` — customization

Add History, the live race screen, guides, or the three-theme showcase if the listing supports more images.

## Files and sizes

- **gallery/*.png:** 2400 × 1800, high-resolution gallery cards.
- **gallery/*.jpg:** 1600 × 1200, smaller upload-ready versions of the same cards.
- **social/*.png:** 1200 × 630, landscape social/link-preview cards.
- **raw/*.png:** 3200 × 2000 original desktop screenshots (the full active-race capture is 3200 × 2400), captured at a 1600 × 1000 viewport and 2× pixel density.
- **contact-sheet.jpg:** preview of all 10 gallery cards.
- **manifest.json:** routes, themes, source screenshots, and export dimensions.
- **build_gallery.py:** composition script; requires Pillow and the macOS Avenir Next font.

## Pages included

Home / typing practice, Learn, an index-finger lesson, Multiplayer Typing Race, an active race lobby and race screen, Ghost Race, Hacker Typer, History, Settings, and the blog / guides index.

## Themes

AMOLED, Nord, and Dracula showcase NinjaType’s appearance options. Hacker Typer has its own CRT Green appearance, independent of the main app theme. The theme collage uses actual captures of the same practice page in three themes; the UI has not been recolored.

## Capture notes

Screenshots show real live-site UI and normal sample interactions. WPM/history values are the browser’s displayed sample session data, not promised outcomes or comparative benchmarks. Cards add headlines and a browser frame; original screenshots remain available separately. All screenshots were checked for capture errors and readable layout. No source code changes or publishing were performed for this screenshot task.
